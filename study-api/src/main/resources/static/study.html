참가 신청

이름을 입력하면 API 응답으로 신청 결과를 확인합니다.

신청 명단 0

COMPLETE는 참가 확정, HOLD는 대기 상태로 표현합니다.

명단을 불러오는 중입니다.
GET /study/participants 원본 응답 응답 대기 중

정원 변경

1명부터 10명까지 입력할 수 있습니다.

정원 변경 성공, 입력 오류, 현재 확정 인원보다 작은 정원 등의 결과를 서버 문자열 그대로 보여줍니다.

사용 API
